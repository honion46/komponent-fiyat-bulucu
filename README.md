# Komponent Fiyat Bulucu V3
Gerçek web araması için başlangıç sürümü. Robotistan ve Direnc.net adapter'ları vardır. Fiyat/stok alanları yalnızca sayfadan doğrulanabildiğinde doldurulmalıdır; uydurma veri üretilmez.

## Çalıştırma
`pip install -r requirements.txt`
`streamlit run app.py`

## Not
Satıcı sitelerinin kullanım koşulları, robots.txt, rate limit ve anti-bot mekanizmalarına uyulmalıdır.
